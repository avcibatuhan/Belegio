# Sample receipts

Eight **fictional** German receipts for trying Belegio. Drag them onto the
Übersicht page or the upload screen.

All merchants, addresses, tax numbers and amounts are invented. Any
resemblance to real businesses is coincidental.

| File | Kind | Shows |
|---|---|---|
| `01-baeckerei.png` | scan | 7 % VAT, cash paid with change (not the total) |
| `02-tankstelle.jpg` | **photo** | Perspective correction, 19 % VAT |
| `03-buerobedarf.png` | scan | Several items, category from the items |
| `04-hosting.png` | scan | A4-style invoice (Nettobetrag / Gesamtbetrag) |
| `05-cafe.jpg` | **photo** | Merchant without a legal form → sent to review |
| `06-fahrkarte.png` | scan | Travel ticket, 7 % VAT |
| `07-mobilfunk.png` | scan | Telecommunications |
| `08-hofladen.jpg` | **photo** | Tax table (`Steuer │ Netto │ Brutto`) read by column |

`truth.json` holds the correct values for each receipt.

The images are generated by [`scripts/make-samples.py`](../scripts/make-samples.py)
(Python with Pillow and NumPy):

```bash
python3 scripts/make-samples.py samples
```
